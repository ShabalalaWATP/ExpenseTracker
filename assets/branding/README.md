# ExpenseTracker brand assets

## Primary mark

`expensetracker-logo.png` is the transparent 1,254 × 1,254 pixel master for the
ExpenseTracker mark. It combines:

- A receipt silhouette.
- A route or tracking trace.
- A completion tick.

The mark contains no text. Render the accessible `ExpenseTracker` wordmark as
live text beside it in navigation and sign-in views.

`expensetracker-logo-source.png` preserves the generated chroma-key source for
future derivative work. It must not be shipped in the production application.

## Usage

- Preserve the mark's aspect ratio and clear space.
- Do not add a currency symbol, shield or enclosing badge.
- Do not recolour state warnings to match the logo.
- Generate and visually inspect favicon and installed-app sizes before launch.
- Use the transparent master from this folder, not the generated-image cache.
